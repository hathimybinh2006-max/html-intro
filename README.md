# Trang web của tôi - HTML Heading & Paragraph

Bài thực hành luyện tập sử dụng các thẻ tiêu đề (heading) và đoạn văn (paragraph) trong HTML.

## Nội dung bài tập
- File chính: \index.html\
- Tiêu đề chính \<h1>\: "Chào mừng đến với trang web của tôi"
- Tiêu đề phụ \<h2>\: "Giới thiệu bản thân"
- Đoạn văn \<p>\: Mô tả sở thích cá nhân
- Đoạn văn \<p>\: Mục tiêu học lập trình
